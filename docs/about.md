# About

**cforqol** — the "c" is for create, code, craft, cook, and the rest of them. The point is the second half: qol. Making life easier.

Everything here exists to save future-me time, money, or annoyance. If a page doesn't clear that bar, it doesn't go in.

Two sections, on purpose:

- **Quick starts** — reference for tools you already use. One screen each.
- **Handbook** — how things are set up, and why. Long-form, dated, kept current.

More categories when there's enough to fill them. Not before.
