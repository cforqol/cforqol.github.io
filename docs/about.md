# About

**cforqol** — the "c" is for create, code, craft, cook, and the rest of them. The point is the second half: qol. Making life easier.

Everything here exists to save future-me time, money, or annoyance. If a page doesn't clear that bar, it doesn't go in.

Three sections, on purpose:

- **[Quick starts](quickstarts/index.md)** — the flags and recipes I actually use. One screen per tool, common arguments only, not a manual.
- **[Setup](setup/index.md)** — how my machines and tools are configured, and why. Long-form: the whole picture for one thing, including the options I rejected.
- **[Handbook](handbook/index.md)** — specific things that broke, and what actually fixed them. Symptoms, cause, fix, how to spot it next time.

Plus **[Tools](tools/index.md)** — things I built. Each one has its own repo, and its docs live there.

The split is deliberate. A command I keep forgetting goes in Quick starts. A machine I configured goes in Setup. A thing that broke goes in Handbook. If a page fits two of them, it's two pages.

More sections when there's enough to fill them. Not before.
